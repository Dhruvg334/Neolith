# Glossary

## Action / Execution Request

A proposed sensitive operation that the agent wants an enterprise service to perform.

## Action Envelope

Canonical structured representation of an execution request.

## Agent

An AI-powered workflow that reasons, plans and uses tools.

## Approval

Human authorisation required by policy for a specific action.

## Budget Reservation

Temporary atomic claim against available spend before execution.

## Decision Receipt

Append-only evidence record describing a governance decision or execution outcome.

## Delegation

Transfer of a subset of authority from one agent or workflow role to another.

## Enterprise Service

Protected downstream system such as ERP, CRM, HR, procurement or scheduling.

## Execution Permit

Short-lived signed token that allows one exact governed action.

## Governance Layer

Independent runtime component responsible for authority validation.

## Intent Continuity

Ongoing check that a proposed action still serves the user's authorised objective.

## MCP

Model Context Protocol, used to expose tools and context to agent systems.

## OPA

Open Policy Agent, used for deterministic policy-as-code evaluation.

## Policy

Organisational rule applied independently of the AI model.

## Principal

Human or enterprise identity from whom authority originates.

## Protected Action

Action with financial, operational, privacy or organisational consequence.

## Risk Signal

Structured evidence that can raise the required scrutiny of an action.

## Runtime Gateway

Entry point through which protected action requests pass.

## Semantic Memory

Retrieved historical context such as prior incidents or documentation. It is non-authoritative.

## Working Memory

Task-scoped agent state used while completing a workflow.
