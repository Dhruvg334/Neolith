# UI / UX Specification

## Product character

Neolith should feel like an enterprise task-control system, not a generic chatbot.

## User navigation

- Tasks
- Approvals
- Activity
- Receipts

## Operator navigation

- Dashboard
- Agents
- Tools
- Permissions
- Policies
- Budgets
- Actions
- Incidents
- Assurance

## Task Workspace

Three-column or staged flow:

1. user goal and conversation;
2. plan/research/comparison;
3. governance/execution status.

## Key visual principles

- recommendation and execution are visually distinct;
- allow/deny/review use icon + text, not colour alone;
- reason codes have human explanation;
- critical action scope is visible before approval;
- user can see which step is AI-generated and which step is governance-controlled;
- audit IDs are copyable.

## Operator Dashboard

Show:

- active tasks;
- protected actions;
- allow/deny/review counts;
- budget reserved/committed;
- pending approvals;
- quarantined agents;
- recent incidents;
- runtime latency.

## Receipt Explorer

Display:

- task;
- user;
- agent/version;
- action;
- policy/version;
- budget result;
- risk signals;
- approval;
- permit;
- execution result;
- hash verification.

## Accessibility

Target WCAG 2.1 AA.
